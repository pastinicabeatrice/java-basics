# Java basics

Exerciții de început în Java.

## Ce conține

- `basics.lab`, `basics.ex` - structuri de decizie, bucle, metode și operații matematice
- `basics.scanner` - citirea datelor de la tastatură cu `Scanner`, clasa `Math` și numere aleatoare
- `inheritance` - ierarhia `Organism` → `Animal` (`Cat`, `Dog`) și `Plant`
- `oop.lab1` - prima clasă: `Car`
- `Student`, `User` - clase simple cu câmpuri, constructori, getteri și setteri

## Rulare

Se deschide folderul în IntelliJ IDEA și se rulează clasa dorită (fiecare are metoda `main`).
